# 拾光书室

维多利亚风格的复古拼贴手账。原生 JavaScript、Three.js 0.160.0，字体与运行资源均已本地化。

## 启动

需要 Node.js 18 或以上。在此目录执行 `npm start`，打开 http://127.0.0.1:4173 。无需安装依赖或构建；不要直接用 `file://` 打开页面。

## 使用

打开游戏直接进入 3D 书桌，点击书本或底部书签后展开。五本书拥有各自的书房配色、装饰和初始拼贴；用「换张纸」切换纸张。点击或拖入素材，选中后可旋转、缩放、复制、置顶、删除；拖动角点缩放，拖动顶部圆点旋转。双击手写条编辑。上传照片时可挑选九种相框，上传后实时预览，确认后才贴入；选中照片用「换模板」保留照片与位置换框。底部添加书页与翻页。「珍藏此页」导出当前双页 PNG。

`⌘ / Ctrl Z` 撤销，`⌘ / Ctrl Shift Z` 重做，`Delete` 删除，方向键微调位置。

五本书分别保存在当前浏览器的本地存储中，不上传照片或创作。清除浏览器数据会丢失手账；PNG 只保存画面，不是可重新编辑的备份。照片限制 20 MB，导入时缩小到最长边 900 像素；一本最多 100 页。

## 显示与性能

首页可选择「自动光影」「轻量 3D」「纸本模式」。低配设备自动降低画布分辨率，场景静止、进入编辑器或切到后台时停止重绘。3D 下载或显卡初始化失败不会阻止选书、照片上传与拼贴；显卡上下文中断时会显示纸本书封，恢复后重新出图。

纸张、封皮和木纹已预制到 `assets/textures/`，首屏无需重新绘制和编码；3D 模块独立异步加载，不依赖 importmap 或远程 CDN，也不再创建第二套 WebGL 渲染器。素材抽屉按需解码缩略图。

## 文件

- `js/scene.js`：按需渲染的 3D 书桌、灯光、上下文恢复与资源清理。
- `js/book-model.js`：圆角书封、弧形书脊、纸芯与金属护角。
- `js/desk-loader.js`、`js/boot.js`：分阶段启动、质量档位与失败降级。
- `assets/textures/`：十八张预制纸张、书封及木纹。
- `js/textures.js`：12 种纸张与木纹、皮革纹理。
- `js/materials.js`：88 件原创 SVG 拼贴素材与 9 种照片模板。
- `js/themes.js`：五本手账的独立书房配色、装饰与初始拼贴。
- `js/app.js`：编辑器、存档与导出。
- `vendor/`、`assets/fonts/`：本地依赖与相应许可证。

素材为程序化绘制；Three.js 使用 MIT 许可，Cormorant Garamond 使用 SIL OFL 许可。`npm run check` 检查脚本语法。
